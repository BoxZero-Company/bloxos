# Security Policy

## BloxOS 27H1 Horizon

Security is an important part of the development of **BloxOS**, an open-source operating system project developed by **BoxZero**.

We appreciate responsible security research and reports that help us identify and address potential vulnerabilities.

## Supported Versions

BloxOS is actively developed, and security support depends on the availability and maintenance of each release.

| Version | Security Support |
|---|---|
| Latest stable release | Supported |
| Experimental previews | Best-effort |
| Older releases | Not guaranteed |

Experimental builds are not intended for production environments.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

**Preferred reporting method:**

Use GitHub Private Vulnerability Reporting if it is enabled for this repository:

https://github.com/BoxZero-Company/bloxos/security/advisories/new

Please do not publicly disclose an unpatched vulnerability through GitHub Issues.

If private vulnerability reporting is unavailable, contact the BoxZero maintainers privately before publishing technical details.

## What to Include

When reporting a security issue, please provide:

- A clear description of the vulnerability.
- The affected BloxOS version or commit.
- The affected component.
- Steps to reproduce the issue.
- Potential security impact.
- Logs or screenshots when relevant.
- Any suggested mitigation, if available.

Please avoid including sensitive personal information in your report.

## Security Scope

Security reports may involve components such as:

- Kernel
- Boot process
- Memory management
- Filesystem
- System services
- Desktop environment
- Package manager
- Installer
- Third-party dependencies

## Responsible Disclosure

We request that security researchers:

1. Give maintainers reasonable time to investigate the report.
2. Avoid accessing or modifying other users' data.
3. Avoid disrupting services or systems.
4. Do not publicly disclose vulnerability details before a fix or coordinated disclosure.
5. Share relevant technical information privately.

## Security Updates

Security fixes and relevant announcements may be published through:

- GitHub Releases
- GitHub Security Advisories
- Official BoxZero channels

## Important Notice

BloxOS is an actively developed operating system project.

Experimental releases may contain security issues, incomplete functionality, or unexpected behavior.

Users should test experimental builds in virtual machines and avoid using them for sensitive or production workloads.
